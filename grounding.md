# Model <-> Standard mapping (PACT Methodology v3 / Catena-X PCF Rulebook v4)

| Model element | Standard basis |
|---|---|
| Cradle-to-gate PCF per unit output | PACT v3 mandatory boundary (cradle-to-gate); Catena-X RB v4 same for parts/intermediates |
| Tier hand-off r_i passed buyer-by-buyer | Catena-X "exchange of PCFs from tier to tier"; PACT Tech Spec v3 (48+ conforming systems) |
| Participant report = own direct emissions + suppliers' handed-over values | PACT hierarchy: supplier-specific PCF preferred over secondary |
| Non-participant replaced by sector-average factor | PACT: secondary data (industry-average EF databases) when supplier-specific data unavailable |
| Tier depth T=1 | PACT baseline practice: primary activity data + secondary upstream factors |
| T -> converged | Fully chained ecosystem (Catena-X vision: "eliminating estimations/secondary data") |
| Primary data share (PDS), emissions-weighted | PACT data model `primaryDataShare` = share of primary data in final absolute PCF (Meth. 4.2.2, SHALL) |
| MC intervals on secondary portions | PACT DQI (Meth. 4.2.3, SHALL-2027); pedigree-style GSD on secondary EFs |

Key citations for paper: PACT Methodology v3 (WBCSD, 2025); PACT Technical
Specifications for PCF Data Exchange v3 (2025); Catena-X PCF Rulebook v4
(Sept 2025); GHG Protocol Scope 3 Technical Guidance; ISO 14067:2018.
